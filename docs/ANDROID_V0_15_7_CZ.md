# Android 0.15.7: údržba sestavení GitHub Actions

Všechny používané veřejné JavaScriptové akce v Android a iOS workflow byly převedeny na aktuální stabilní vydání s Node 24. Checkout neukládá GitHub přihlašovací údaje do pracovního adresáře runneru. Android workflow spouští integrační kontroly, unit testy, sestavuje demonstrační i DJI APK, kontroluje klíč a podpis a vydává instalační soubor v ZIP.

Tato údržba nemění firmware Mini 2 ani chování RTH. Úspěšné sestavení není potvrzením fyzického letu. Před použitím autonomního letu ověřte skutečnou telemetrii, Home Point a ovládání na konkrétním dronu v bezpečném otevřeném prostoru.
