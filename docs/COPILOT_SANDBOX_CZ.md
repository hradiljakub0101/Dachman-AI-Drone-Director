# Projektové nastavení sandboxu v aplikaci GitHub Copilot

Tento dokument popisuje požadovanou politiku pro místní projekt Dachman AI Drone Director. **Není to konfigurační soubor aplikace Copilot a jeho uložení sandbox nezapíná.** Copilot app uchovává projektová nastavení mimo repozitář; místní relaci musí vlastník přepnout nebo restartovat přímo v aplikaci.

1. V nastavení GitHub Copilot aplikace otevřete projekt tohoto repozitáře a zapněte **Sandbox new sessions**. Pro již běžící místní relaci použijte `/sandbox on`; po dalších úpravách pravidel proveďte `/restart-session`.
2. **Filesystem:** Ponechte jen výchozí pracovní složku projektu pro čtení a zápis. Pro dočasné soubory použijte vyhrazenou složku uvnitř projektu (například `.copilot-tmp`, která musí být ignorovaná Gitem); celý uživatelský profil, systémové `/tmp` nebo jiné projektové složky jako additional read/write nepovolujte. V seznamu **Denied** nastavte skutečné umístění podpisových klíčů, produkční konfigurace a jiných tajných souborů, pokud se nalézají v projektu nebo vedle něj. Samotná přípona souboru nebo tento dokument přístup nezablokují.
3. **Credentials:** Vypněte **Git credentials** a **GitHub CLI credentials** pro práci agenta. Aktualizace na GitHubu se pak musí provést zvlášť mimo tuto omezenou relaci.
4. **Network:** Vypněte **Local network** a pro nejnutnější místní práci také **Outbound internet**. Závislosti a instalační APK lze stáhnout a sestavit v GitHub Actions mimo lokální sandbox. Copilot app nabízí pro outbound přepínač, ne vestavěný seznam jednotlivých povolených domén; požadavek „jen vybrané build služby“ lze vynutit až odpovídajícím externím proxy nebo firewallem. Bez toho nepovažujte zapnutý outbound za omezený na registry.
5. Omezte **Run outside the sandbox**: nepotvrzujte obejití omezení pro build ani kvůli přístupu k tajným souborům. Na Windows může požadavek na Denied cesty při nedostupném vynucení skončit chybou „unsupported policy“; oprávnění se tím nemají automaticky otevřít. Po restartu zkontrolujte účinnou politiku v aplikaci.

Pro přímý lokální Android build by byly podle aktuálního projektu potřeba nejméně Gradle distribuce, Gradle Plugin Portal, Google Maven/Android SDK, Maven Central, DJI Maven repozitář a `storage.googleapis.com` pro model EfficientDet. Přesměrování a další domény se mohou lišit. Bez samostatného řízeného proxy nelze jejich omezení v samotné aplikaci Copilot věrohodně zapnout; doporučenou cestou je lokálně síť zakázat a build spustit na GitHub Actions.

Projektové nastavení sandboxu aplikace Copilot neomezuje GitHub Actions runnery ani cloudové/remote relace Copilotu. Podpisové klíče nikdy nevkládejte do repozitáře ani do dočasné složky. Naše debug APK se sestavuje bez produkčního signing keystore; hodnota DJI Android App Key se do DJI APK vkládá z GitHub Actions secretu a není podpisovým klíčem.
