# Dachman launcher icon

`dachman-logo-source.jpg` is the supplied source photograph. The Android launcher
asset removes only the page margins and off-centre placement, then keeps the
black background and white nested-square mark.

Android resources include legacy density PNGs, adaptive icons for Android 8+
and monochrome themed icons for Android 13+. The foreground mark stays inside
the adaptive safe zone so circular and rounded-square launchers do not crop it.
